# B key opens the New Waypoint menu + sharp menus

- Press B: the "New Waypoint" menu opens (no instant waypoint any more). It is already filled with your
  position, a name and your current dimension. Change the name, X/Y/Z, dimension and color, then press
  "Create Waypoint". "< Cancel" or the X closes it and returns you to the game.
- The J menu (and the New/Edit menu) no longer use Minecraft's blurred background. The world behind is
  just dimmed, so the menus look clear and sharp.
- /wp add <name> still adds an instant waypoint if you want one.
